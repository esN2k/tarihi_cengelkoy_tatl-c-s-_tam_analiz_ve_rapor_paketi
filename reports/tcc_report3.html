Bu neden Ticimax'ın yapısal sorunu?
Ticimax, .NET tabanlı eski bir altyapıyla çalışmaktadır. Platform, JavaScript dosyalarını async/defer kullanmadan yüklüyor (render-blocking), 413 KB kullanılmayan JavaScript gönderiliyor, 111 KB kullanılmayan CSS var ve sayfa başına HTML boyutu 664 KB'ı aşıyor. Bunlar ajansın değil, platformun mimarisi kaynaklı sorunlardır.
